# イベントの日付フィルター

`data/config-user.jsonc` の `eventDateFilter` で設定します。設定変更後はページを再読み込みしてください。

- `use`: 有効・無効。
- `category`: 日付選択時に表示するカテゴリの値。現在は `イベント`。
- `label` / `allLabel`: 日付選択の見出し・全日程の表示名。
- `dates`: 選択肢の配列。`{ "value": "2026-11-21", "label": "11/21(土)" }` の形式。ISO日付文字列だけでも指定できます。イベントのない日も登録できます。
- `activityDates`: 投稿IDごとの開催日配列。例: `"WP/647": ["2026-11-21", "2026-11-28"]`。同じ施設の別イベントは別IDで設定します。
- `dateField`: `activityDates` にIDがない投稿で参照する構造化フィールド名。既定値は `event_dates`。値は `["2026-11-21"]` のような日付配列です。自由記述の `eventdate` は自動解析しません。

日付選択はメニューから独立した地図上の横並びボタンです。スマートフォンでは横スクロールできます。日付は「11/21(土)」形式で表示し、土曜日は青、日曜日は赤で区別します。初期状態は日付未選択です。日付ボタンを押すと「イベント」カテゴリに切り替え、その日に開催されるイベントの一覧と施設アイコンを表示し、施設詳細内の企画も同じ日付で絞り込み、施設リストを広げます。縦長画面ではリストが画面下側の65％を占め、上側に地図と日付ボタンを残します。横長画面では通常の左右分割表示にします。「全ての催し物」ボタンでは日付とキーワードを解除し、カテゴリを自動選択（🌏おまかせ）へ戻して、施設リストも標準の高さ（縦長画面の35％）に戻します。カテゴリを切り替えると日付を解除します。地図の移動やズームでは日付を維持します。日付とキーワードを併用すると、その日のイベントから検索します。日付未選択時は従来のキーワード検索の動作を維持します。

日付未登録の投稿は「全ての催し物」で表示し、特定の日付では表示しません。明示的な空配列 `[]` は投稿側の日付より優先します。新規イベントの追加・IDの変更時は対応する設定を更新してください。地図側は `poiView.poiFilter: "filter"` として一覧に連動させてください。

## 初期データ

添付の `1023スケジュール2026 東_1_.xlsx` と `スケジュール2026西ブル_1_.xlsx` のイベント日程を、既存イベント投稿21件のIDに対応付けています。2026年11月21日〜29日を選択可能とし、「いつでも」のオンラインイベントは全日程に登録しています。展示・飲食店の営業時間はイベント日程には含めません。メールアドレスや担当者情報は設定に含めません。

西スケジュール19行目の「高校生が奏でる20世紀名曲ライブ」は、P19の説明が11月23日、T19の日別欄が24日と食い違っています。現在の投稿 `WP/617` の日付も23日のため、説明欄に合わせて23日としています。確定日が変わった場合は `activityDates` の該当IDを修正してください。
