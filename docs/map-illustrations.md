# 十三アートフェス2026の額縁

ひがよどアートフェスマップ2026と同じ金色の額縁を、`data/config-user.jsonc` の `mapIllustrations` で有効にしています。

- 画像: `image/juso-map-frame.png`（中央透過）、編集元: `image/juso-map-frame.svg`
- 額縁の内側左上に `image/splash.png`、右下に `image/sanyodo.jpg` を配置しています。縦横比を保ち、地図と同じ位置に固定します。
- 外周: 西135.4705、東135.501、南34.712、北34.733
- 十三の会場と淀壁全体を囲む範囲に固定し、地図と一緒に回転・傾斜・拡大縮小します。
- 会場アイコン・名称より下に描画し、クリックやドラッグを遮りません。
- PC・スマートフォンとも同じ位置に表示し、画面外の部分は地図でクリップします。
- 会場を詳しく見る倍率では額縁の一部が画面外になります。縮小すると全体を確認できます。

以前の `moto_data` 画像に依存する回帰テストとテスト用設定は削除したままです。
