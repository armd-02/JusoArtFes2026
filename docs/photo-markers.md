# 写真付きの施設アイコン

`data/config-user.jsonc` の `icon.photoMarkers` で設定します。このマップでは有効です。設定がない場合は従来のアイコンを表示します。

```json
"photoMarkers": {
    "use": true,
    "maxMarkers": 100
}
```

施設に紐づく投稿をデータの順番で確認し、投稿フォームの `image_url` 項目で最初に値のある画像を使います。フォームが未定義の場合は `picture_url1`、`picture_url2`…の順です。投稿画像がなければ、OSMの `image`、`wikimedia_commons=File:…` の順で確認します。

独自の画像項目を使う場合は `imageFields: ["photo", "picture_url1"]` のように、保存先の項目名を優先順に指定できます。Wikimedia Commonsの画像は既存のAPIキャッシュを使って小さい画像URLを取得します。

`indoor.use: false` の場合、OSMの `level` に1以上（2階以上）が含まれる施設の写真には影を付けます。階数が未登録の施設には付きません。

写真は丸く切り抜き、訪問済みなどの枠色とお気に入りのハートを表示します。クリック・キーボード操作で通常と同じ施設詳細を開きます。クリック位置で複数の施設が重なる場合は「開く地物を選択」の候補一覧を表示します。通常アイコン、写真サムネイル、3Dモデルを同じ候補一覧で選択でき、1件だけの場合は直接詳細を開きます。大きさは既存マーカーのズーム設定に追従し、`size: 40` のように固定のピクセル数を指定することもできます。3Dモデルが表示される施設ではモデルを優先します。

写真は現在のマーカー表示対象から施設ごとに1枚を選び、最大 `maxMarkers` 件、同時に4枚まで読み込みます。読み込み完了までは従来のアイコンを残し、取得失敗時も従来アイコンを表示します。画像のない施設、設定を無効にした場合も同様です。地図の移動・絞り込みで対象外になった写真は取り除きます。

外部サーバーがCORSを許可していない画像も表示できるよう、HTML画像を地図に重ねています。写真は正方形に中央トリミングして表示します。画像を配信するサーバーの速度や公開状態によっては、通常アイコンのままになることがあります。

確認: `node tests/photo-markers.cjs`、`node tests/marker-overlap.cjs`
