# スタンプ設置場所の表示

`data/config-user.jsonc` の `stampMarkers` で、紙のスタンプラリーの設置場所を指定します。

```jsonc
"stampMarkers": {
    "use": true,
    "osmIds": ["node/9905603114", "way/234567890"],
    "ringColor": "#D65C8C"
}
```

IDは要素種別を含めた完全一致です。前後の空白だけを除き、数字だけのIDや不正な形式は対象にしません。設定した地物は、静的OSMデータまたは読み込み対象のOSMデータに存在する必要があります。`use: false` または空のID一覧で表示を無効にできます。色は `#RRGGBB` 形式で指定し、不正な値は既定のピンクを使用します。

通常マーカーは外周を太いリングで強調し、左上にスタンプバッジを表示します。写真マーカーも写真・既存の枠を維持して外周リングとバッジを追加します。お気に入りのハートは右上です。マーカーを選ぶ操作、絞り込み、ズームに伴うサイズ変更は既存の処理を使います。地図の凡例に「スタンプ印＝現地のスタンプ設置場所」と表示します。

指定した地物を検索条件にかかわらず表示する設定ではありません。既存のカテゴリ・日付・表示範囲・階数などによって地物が非表示の場合、装飾も非表示です。3Dモデルそのものへの装飾は対象外です。

初期設定は藤井米穀店、みんなの図書館さいくる、Cafe Yutte、小竹医院前の掲示板、第七藝術劇場、グランドサロン十三の6か所です。デジタルでの押印や収集履歴は扱いません。

## 共通実装の変更範囲

このリポジトリ内の `lib/poilib.js`（ID照合・通常マーカーのリングとバッジ・写真用候補データ）、`lib/photomarkerlib.js`（写真バッジ）、`system.css`、`cmapmaker.js`（既定で無効の設定項目）を変更しています。バッジの図形は通常マーカーではローカル生成画像、写真マーカーでは `icon/stamp.svg` を使用します。凡例はこのサイトの `index.html` にあります。Community Map Maker本体への反映は別作業です。

検証: `node tests/stamp-markers.cjs`、`node tests/photo-markers.cjs`、`node tests/poi-favorite-marker.cjs`、`node tests/marker-overlap.cjs`。
